# v1.1 Plan — "Reminders that adapt to you"

Positioning wedge (decided 2026-08-15): **simplicity + smart reminders**. Sip is
"the water app that doesn't nag" — no mascots, no guilt, no spam. v1.0 already
ships the core (reminders stop at goal, count scales with remaining, quick-log
from the banner); v1.1 deepens that moat.

## Competitive read

| App | Moat | Exploitable weakness |
|---|---|---|
| Waterllama (4.9★, ~150K ratings) | Charm, animated characters | Fast paywall; toy more than tool |
| WaterMinder (since 2013) | Deepest Watch/HealthKit/widget integrations | Dated design, zero personality |
| Plant Nanny (4.7★, ~105K ratings) | Grow-a-plant guilt loop | Gamification fatigue; nagging feels childish |

Reminder fatigue is the #1 complaint in all three apps' 1-star reviews. We win
by being the app that respects attention, then expand (widgets/HealthKit) later.

## Features (do now — ~2 weekends)

1. **Adaptive backoff** — if 2 reminders fire with no log in between, double the
   gap for the rest of the day and switch to softer copy ("We'll check in
   later"). Pure TS in `src/logic/reminders.ts`, no new permissions. ~half day
   incl. tests. The killer anti-nag feature no competitor has.
2. **Snooze action** — "Not now (1h)" button next to "Log 250 ml" on the
   notification. One category change in `src/notifications.ts`. ~2h.
3. **Pace-aware spread** — weight reminders toward the afternoon when behind
   pace at midday instead of spreading evenly; mornings stay quiet. ~half day.
4. **Evening cutoff intelligence** — if history shows no logging after ~8pm,
   stop reminding earlier automatically. Uses existing history data. ~half day.
5. **Pro seam stays dormant** — everything above ships free. The ~$9.99
   one-time Pro IAP (`src/pro.ts`) waits for v1.2 when widgets/HealthKit give
   it something premium to unlock.

## Deferred to v1.2

- HealthKit workout detection → goal bump / extra reminder (needs native module + config plugin).
- Lock-screen widget / Live Activity (needs native targets).
- Weather-aware goals — needs location permission, which would break the
  "Data Not Collected" privacy label (a real store asset). Decide deliberately.

## Growth playbook (free-first, in order)

1. **App Store SEO** — target long-tail ("calm water reminder", "gentle
   hydration") not head terms; copy above does this.
2. **Communities** — r/HydroHomies (1M+), r/ADHD, r/productivity: post as a
   solved-problem story ("I built a water reminder that stops nagging"), not an ad.
3. **Apple feature bait** — adopt new iOS APIs fast (interactive widgets, Live
   Activities) in v1.2; Apple features small apps that showcase new APIs.
4. **Short-form video** — 15s "POV: your water app actually backs off" clips;
   judge only after ~a month of 3–5/week.
5. **Later, not now** — paid ads, influencers, cross-promo; wait for conversion data.
